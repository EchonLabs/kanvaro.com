## 4. Findings from this task

| # | Finding | Effect |
|---|---|---|
| — | Team members can log time manually only if the organisation setting `allowMembersToAddTimeLogs` is on (off here). Admin, HR and super admin can log for anyone. | The `time_log` tool will be refused for team members unless the organisation enables it. Mention this in the tool description. |
| — | Creating time entries works only with the cookie (F3 confirmed again) | The seed sends the cookie for that call |
| — | Task, story, epic, sprint, project, comment, dependency and custom-role creation all **work with the Bearer token** | Confirms wave 2 writes need no Kanvaro change |

## 5. Commands

```bash
npm run dev                                         # Kanvaro on :3000
node mcp-server/tools/seed-test-users.cjs           # users (re-run resets passwords)
node mcp-server/tools/seed-test-data.mjs            # data (needs Kanvaro running)

node mcp-server/tools/seed-test-data.mjs --remove   # remove data and custom role
node mcp-server/tools/seed-test-users.cjs --remove  # remove users
```

Both scripts refuse to touch a non-local database unless `ALLOW_NON_LOCAL=1` is set.
